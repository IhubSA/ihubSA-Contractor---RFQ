TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────
Issue: "No RFQ Found" message
  → Check URL has correct ?rfq=TOKEN
  → Verify token hasn't been used (you can only use a link once)

Issue: Files won't upload
  → Check rfq-documents bucket exists in Storage
  → Verify it's set to Private
  → Check file format (PDF, Word, Excel only)

Issue: Styling looks wrong
  → Hard refresh browser (Ctrl+Shift+R)
  → Check styles.css is in same folder as index.html
  → Clear browser cache
